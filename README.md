# 📱 GDK Chit Fund App

The **GDK Chit Fund App** is a cross-platform mobile application built with **React Native** to simplify chit fund operations for both Android and iOS users. With over **20 years of trusted service**, it brings a traditional financial system into the digital age, making chit fund management secure, transparent, and accessible anywhere.

## 🔑 Overview
The app provides a **modern dashboard** where members can view real-time portfolio updates, track investments, and quickly access essential functions. Designed with **Material Design principles**, it delivers a smooth, clean, and responsive experience across devices.

## 👤 Profile & Account Management
Members can manage their personal details, nominees, and linked bank accounts, and also complete identity verification—all in one place. Built-in **security and privacy features** ensure user data is protected through strong authentication and compliance with privacy standards.

## ✨ Features
- Real-time investment and portfolio tracking  
- Smooth slide-in animations with React Native Animated API  
- Secure authentication and permissions  
- Nominee and bank account management  
- Integrated help and support (FAQs, customer service, social media links)  
- Optimized for Android & iOS with responsive layouts  

## 🛠️ Tech Stack
- **Framework**: React Native  
- **State Management**: React Hooks  
- **UI/UX**: Material Design with custom styling  
- **Navigation**: Animated slide-in transitions  

## 🚀 Why GDK Chit Fund?
Since **2005**, GDK Chit Fund has built a legacy of trust. This app extends that trust digitally, giving members the tools to **track, manage, and grow their investments with ease**. Whether monitoring contributions or updating account details, everything is just a tap away.
